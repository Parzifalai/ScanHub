# Логотип ScanHub — «Поворот»

**Идея.** Табличка, как в оформлении окна ScanHub (синяя, с белой окантовкой), а в ней S — дорожная стрелка «вперёд, разберёмся». ScanHub не пугает щитом, а показывает, что не так, и ведёт по шагам.

## Файлы

| Файл | Где использовать |
|---|---|
| `scanhub-symbol.svg` | основной знак — от 48 px и крупнее |
| `scanhub-symbol-small.svg` | упрощённый знак для 16–40 px: без тонкой окантовки, S толще (значок окна, панель задач, вкладка) |
| `scanhub-symbol-dark.svg` | на тёмном фоне (чуть светлее синий) |
| `scanhub-symbol-white.svg` | белая табличка с синей S — на синем или цветном фоне |
| `scanhub-symbol-black.svg`, `scanhub-symbol-small-black.svg` | ч/б печать |
| `scanhub-symbol-mono-*.svg`, `scanhub-symbol-small-mono-black.svg` | одноцветные: S и окантовка — вырезы (гравировка, штамп, наклейка одной краской) |
| `scanhub-horizontal.svg` | знак + надпись на светлом фоне (README, сайты) |
| `scanhub-horizontal-on-dark.svg` | знак + надпись на тёмном фоне |
| `scanhub-horizontal-black.svg` | знак + надпись в ч/б |
| `scanhub-wordmark.svg`, `scanhub-wordmark-white.svg` | только надпись |
| `scanhub-512.png`, `scanhub-1024.png` | растровый знак (аватарки, соцсети) |

Значки окна и программы: `ui/logo.svg`, `ui/logo-small.svg`, `ui/icon-32.png`, `ui/icon-256.png`, `ui/scanhub.ico` (16–256 px; до 48 px — упрощённый знак). Собираются скриптами `dev/build_logo.py` → `dev/export_icons.py`.

## Цвет

| | HEX | RGB | Где |
|---|---|---|---|
| Синий ScanHub | `#2456D6` | 36 86 214 | табличка, кнопки в окне |
| Синий на тёмном | `#3563E9` | 53 99 233 | табличка на тёмном фоне |
| Белый | `#FFFFFF` | 255 255 255 | S и окантовка |
| Графит | `#141820` | 20 24 32 | надпись на светлом фоне |

Белое на синем `#2456D6` — контраст 6,2:1, на `#3563E9` — 5,1:1 (оба проходят WCAG AA).

## Шрифт

Надпись — Bahnschrift SemiBold (шрифт оформления окна), буквы переведены в контуры: в файлах нет живого текста, шрифт для показа не нужен.

## Правила

- **Свободное поле** вокруг знака — не меньше четверти его ширины.
- **Минимальный размер:** основной знак — 48 px, упрощённый — 16 px; горизонтальный вариант — 120 px в ширину.
- **Фон:** светлый — основной знак; тёмный — `-dark`; синий или цветной — `-white`; фото — только на спокойном участке.
- **Нельзя:** перекрашивать S или табличку в другие цвета, убирать стрелку, поворачивать и растягивать знак, добавлять тени и градиенты, ставить надпись слева от знака или другим шрифтом, класть знак на пёстрый фон без подложки.
